# 進捗報告のスライド（Typst）

進捗報告のスライドは Typst で書き、PDF にして Google Drive に上げる。Claude は、報告のフォルダ、スライドの下書き、PDF を用意する。ユーザーは、図と文言を直し、Drive にアップロードする。Google Drive と Claude は連携しない。

この文書には、フォルダの構成、作業の流れと分担、ユーザー向けの Typst の書き方をまとめる。Claude が守るルールは [`rules/slides.md`](rules/slides.md) に、Claude の手順は skill `make-progress-slides` に書いてある。

## フォルダの構成

```
slides/
  template/progress.typ    テンプレート（見た目をすべて決める）
  diagrams/                PowerPoint で作った図（.pptx と、書き出した .png）
  progress/<YYYY-MMDD>/    報告ごとのフォルダ（名前は報告日）
    <YYYYMMDD>.typ         スライドの本体
    <YYYYMMDD>.pdf         できあがったスライド
    figures/               スライドに載せる図のコピー
    copied/                過去のスライドの画像（ユーザーが置く）
    extras/                スライドに載せないが、報告で見せるもの（音声、.fig）
```

- `slides/` の下は、すべて git で管理する。他の PC と共有でき、`.typ` を直した履歴も残るためである。
- `figures/` には、`results/figures/progress/` などから図をコピーする。進捗報告用の図は上書きして作り直すことがあるので、コピーしておけば報告で見せた図が残る。
- `extras/` は、見せるものがある回だけ作る。
- 例：2026/11/17 の報告は `slides/progress/2026-1117/20261117.typ` である。これは、Google Slides で作ったスライドを、テンプレートの試しとして写したものである。

## 作業の流れと分担

分担は最初の案で、これから話し合って直していく。

1. ユーザーが、報告日を伝えて、スライドを作るよう Claude に頼む。
2. Claude が、報告のフォルダを作る。進捗ログ（`docs/progress/`）と進捗報告用の図（`results/figures/progress/`）から、スライドの下書きを作る。
3. ユーザーが、コピーする過去のスライドを決める。
   - (a) Google Slides で作った回は、そのスライドの画像（PNG）か1ページの PDF を、`copied/<MMDD>_p<ページ番号>.png` の名前で置く。
   - (b) Typst で作った回は、どの回の何ページかを Claude に伝える。
4. Claude が、コピーしたスライドを入れる。
5. ユーザーが、プレビューを見ながら、図と文言を直す。直したい所を Claude に頼んでもよい。
6. Claude が PDF を作り、すべてのページを確かめる。
7. ユーザーが、報告のフォルダのうち `.typ` 以外のファイルを、Drive にアップロードする。

Claude に任せないことは、次のとおりである。

- 過去のスライドのうち、どれをコピーするかを決めること
- 実装に関係しない事項（自分の論文の共有、学会の申し込みなど）のスライドを書くこと

### まだ決めていないこと

次のことは、スライドを一緒に作りながら決め、この文書と [`rules/slides.md`](rules/slides.md) に書き足す。

- スライドのデザイン（今のテンプレートは、Google Slides で使っていた見た目を写したもの）
- どこまで Claude に任せるか
- タイトルと本文の文言の指針
- 強調の図形の位置を指定しやすくする仕組み（PowerPoint のルーラーのようなもの）

## Typst の書き方（ユーザー向け）

### プレビューと PDF

スライドを直すときは、VS Code の拡張機能 Tinymist のプレビューを使う。

1. VS Code で、このリポジトリのフォルダを開く。
2. 報告のフォルダの `.typ` を開く。
3. コマンドパレット（Ctrl+Shift+P）で「Typst Preview」と入力し、「Preview Opened File」を選ぶ。横にプレビューが出て、`.typ` を直すたびに更新される。

プレビューの文字をクリックすると、`.typ` の対応する所へ移れる。テンプレートが `slides/template/` にあるため、プレビューが「root の外のファイルを読めない」というエラーを出すことがある。そのときは、VS Code の設定 `tinymist.rootPath` に、このリポジトリのフォルダを指定する。

PDF は、リポジトリの直下で次のコマンドを実行して作る（例は 11/17 の回）。`.typ` と同じフォルダに、同じ名前の PDF ができる。`--root slides` は、別のフォルダにあるテンプレートを読めるようにするための指定である。

```bash
typst compile --root slides slides/progress/2026-1117/20261117.typ
```

### 文の書き方

| やりたいこと | 書き方 |
|---|---|
| 段落を分ける（Google Slides の Enter） | 空行を1行入れる |
| 項や段落の中で改行する（shift+Enter） | 行の末尾に `\` を書く |
| 箇条書き（●） | 行の頭に `- ` を書く |
| 箇条書きの2段目（○、16pt） | 2文字下げて `- ` を書く |
| 番号付きの箇条書き | 行の頭に `+ ` を書く |
| 太字 | `*太字*` |
| 小さい字の補足（16pt） | `\` で改行した後に `#note[補足]` |
| 文字の背景を薄い赤で塗る | `#hl[強調]` |
| 空の行を1行入れる | `#blank` |
| 数式 | `$y_c = (sum_i y_i D_i) / (sum_i D_i)$` |
| 記号 `*` `#` `_` `$` `\` そのもの | 前に `\` を付ける（`\*`） |

- 1つの段落は、途中で改行せずに1行で書く。ソースの改行は、日本語の文字の間でも空白になるためである。
- 数式の書き方が分からなければ、Claude に LaTeX の書き方で伝えて、書き換えてもらう。

例（11/17 の8ページ目に近い形）：

```typst
#slide(title: [自動追跡の外れ値の解析], title-note: [(11/12追記)])[
  - 画面中央の2, 3点を溝底の点として誤検出したことが判明 \
    #note[（ギリギリ溝底と言える場所には位置している）]
  - 溝底の下側に暗い部分が生じているのが原因

  →*点の抽出方法を見直したい*
]
```

### 図を置く

図は `fig-at` で、決まった範囲に置く。図は範囲に収まる最大の大きさになり、下にファイル名が自動で付く。

```typst
#fig-at(..cell-left(), image("figures/a.png"))
#fig-at(..cell-right(), image("figures/b.png"))
```

| 範囲 | 置く所 |
|---|---|
| `cell-left()`・`cell-right()` | 左右に2枚並べる |
| `cell-full()` | 本文の幅いっぱいに1枚（横長の図） |
| `cell-side()` | 右に1枚。左の文は `#side-text[...]` に書く |

- 範囲の上端は、既定では 150pt（本文2行の下）である。上の文が長くて図と重なるときは、`cell-left(top: 180pt)` のように変える。
- 図の一部だけを見せるときは、`crop: (左, 上, 右, 下)` を付ける。値は、図の幅・高さに対する割合（0〜1）である。
- `image()` には、大きさ（`width`・`height`）を付けない。
- 文を左右2列に分けて図の上に書くときは、`#cols[左の文][右の文]` と書く。列の幅は、左右の図の範囲とそろう。

### 強調の図形

図の上の図形は、`fig-at` の `marks:` に書く。位置と大きさは、図の幅・高さに対する割合（0〜1）で書く。PowerPoint と同じく、図形を囲む四角の左上 (x, y) と、幅・高さで指定する。

```typst
#fig-at(..cell-right(), image("figures/b.png"),
  marks: (mark-oval(0.42, 0.48, 0.22, h: 0.09),))
```

図と図の間の矢印や、スライドの上の文字は、`#draw(...)` で描く。座標は、スライドの左上を原点とする pt で書く。スライドの大きさは 720pt × 405pt である。

```typst
#draw(
  mark-arrow((328pt, 272pt), (392pt, 272pt)),
  mark-text(344pt, 250pt, [拡大]),
)
```

| 図形 | 書き方 | 既定 |
|---|---|---|
| 丸・楕円 | `mark-oval(x, y, 幅, h: 高さ)`（`h` を省くと円） | 赤、0.75pt |
| 四角 | `mark-rect(x, y, 幅, 高さ)` | 赤、0.75pt |
| 線 | `mark-line((x1, y1), (x2, y2))` | 赤、0.75pt |
| 矢印 | `mark-arrow((x1, y1), (x2, y2))` | 黒、1.5pt |
| 文字 | `mark-text(x, y, [文字])` | 黒、14pt |
| 吹き出し（白塗り・黒枠） | `mark-callout(x, y, [文字])`（`center: true` で中央揃え） | 20pt |

線の太さは `stroke: thick` のように変えられる。`thin`（0.75pt）・`medium`（1.5pt）・`thick`（3pt）は、Google Slides の 1px・2px・4px にあたる。色は `color: black` のように変える。

### 過去のスライドをコピーする

Google Slides で作った回のスライドは、画像を `copied/` に置き、次のように書く。右上に赤字で「11/03のスライド」と付く。

```typst
#copied-slide(image("copied/1103_p9.png"))
```

Typst で作った回のスライドは、その回の `.typ` から `#slide(...)` をコピーし、`copied-from: "11/03"` を足す。文言を後から直せる。

## PowerPoint の図

アルゴリズムの説明図のように、GUI で描きたい図は PowerPoint で作る。

1. `.pptx` を `slides/diagrams/` に置く。
2. 図を PNG で書き出し、同じフォルダに同じ名前で置く。名前は、何の図かが分かる英語にする（例：`grooveTrackingAlgorithm_step1`）。
3. スライドで使うときは、PNG を報告のフォルダの `figures/` にコピーする。

過去の回の図を使い回すときも、`slides/diagrams/` から探す。
