# SPレコード音声復元プロジェクト

SPレコードの盤面写真から音溝（溝底）の形状を読み取り、音声を復元するためのMATLABプロジェクトです。

## ディレクトリ構成

- **`Research.prj`**: MATLABプロジェクトファイル
- **`src/`**: プロジェクトの主要クラス定義
  - `ImageData.m`: レコード盤面の画像データを管理するクラス
  - `DarknessValue.m`: 画像の暗度しきい値から溝底の候補を抽出するクラス
  - `GrooveCandidates.m`: 抽出された溝底の候補点を保持・表示するクラス
  - `AudioData.m`: 復元した音声データの描画、保存、再生を行うクラス
- **`scripts/`**: 溝底抽出アルゴリズムや解析用のスクリプト群
- **`test/`**: テスト用コードおよび評価用ファイル

## 基本的な使用方法

1. MATLABで **`Research.prj`** を開いてプロジェクトを起動します。
2. コマンドウィンドウまたはスクリプトで以下を実行し、プロジェクトのルートフォルダを取得します。
   ```matlab
   proj = currentProject;
   rootFolder = proj.RootFolder;
   ```
   ※ プロジェクト内のファイルへのアクセスやパスの指定は、ここで取得した `rootFolder` を基点として行ってください。
3. レコードの盤面画像を読み込み、`src/ImageData.m` や `src/DarknessValue.m` クラスを利用して溝位置を抽出します。
4. 抽出した溝の形状変化から音声信号を生成し、`src/AudioData.m` クラスを用いて試聴やwavファイルへの書き出しを行います。
