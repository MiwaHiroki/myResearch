# 図を作る

ルールの中身は [`docs/rules/figures.md`](../../../docs/rules/figures.md) が正。このskillは、それに沿って図を作る手順だけを書く。ルールを書き写さない。

## 1. ルールを読む

`docs/rules/figures.md` を読む。前に読んでいても、語彙表は変わることがあるので読み直す。

## 2. 用途を決める

ユーザーの言葉から、作業用・進捗報告用・スライド用・原稿用のどれかを決める。分からなければ尋ねる。用途で、次が決まる（figures.md の「置き場所と用途」の表）。

- スクリプトの置き場所と出力先
- タイトルを付けるか
- 大きさ・文字の大きさ
- 保存関数（`saveFigure`・`saveSlideFigure`・`savePaperFigure`）

同じ図を作るスクリプトが既に無いかを、`scripts/` で探す。あれば、それを直すか、新しく作るかをユーザーに確かめる。

## 3. 名前を決める

figures.md の「ファイル名」に沿って、語彙表の語だけで組み立てる。

1. 種類（何を描いた図か）
2. 比較（比べた図だけ。違う条件を `Vs` でつなぐ）
3. 条件（図が依存するものをすべて。語彙表の順）
4. データの日付（cycleResult を読む図だけ。読み込む `experiments/<MMDD>/` の日付）
5. 部分・範囲・表示

- 語彙表に無い語が要るときは、似た語で代用せず、ユーザーに確かめてから、figures.md の表と `src/figureVocabulary.m` の両方に足す。
- 名前は、スクリプトのパラメータの変数から組み立てる。手で打たない。
- 決めた名前は、書く前に `mcp__matlab__evaluate_matlab_code` で `checkFigureName("<名前>")` を実行して確かめてよい（worktree では、その worktree の `src/` を `addpath` してから呼び、終わったら `rmpath` する）。

## 4. タイトル・凡例・軸ラベルを書く

- タイトル（作業用・進捗用だけ）は、ファイル名と同じ情報を、語彙表の「表記」の列の語で、同じ順に書く。
- 凡例の、比べたものの名前は「表記」の列の語で書く。
- 軸ラベルは「量 [単位]」の英語。

## 5. 保存する

- 用途の保存関数で保存する。`exportgraphics`・`saveas` を直接呼ばない。
- 出力先に同じ名前のファイルが無いかを、実行する前に確かめる（`docs/rules/data.md` の「出力の上書き」）。

## 6. 実行して確かめる

- MATLAB は全セッションで共有している。他のセッションがスクリプトを実行していないときに、`mcp__matlab__run_matlab_file` で実行する。`Research.prj` が開いていなければ開き直す。`ginput` が要るスクリプトは、保存した選択を再現できるときだけ実行する。
- 実行の出力に `checkFigureName:invalidName` の警告が無いことを確かめる。出ていれば、名前を直して実行し直す。
- スライド用・原稿用は、保存関数が表示する実際の大きさが、指定した大きさとずれていないかを確かめる。
- 書き出した PNG を Read で開き、目で確かめる：凡例と線・マーカーの重なり、ラベルやカラーバーの見切れ、タイトルの有無（用途どおりか）、軸ラベルの単位。

## 7. 報告する

作った図のパス（`[名前](相対パス)` のリンク）と、決めた名前の要素（種類・比較・条件・日付）を短く書く。語彙表に語を足したときは、そのことも書く。
